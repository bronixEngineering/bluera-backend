🔵 Bluera ($BLU) — Product Specification (V1)
________________


1. Problem Statement
Farcaster is the social graph of crypto, but it lacks integration with onchain identity. Current mini apps highlight what users say, not what they do.
* No single tool connects Farcaster IDs (FIDs) with their Base wallet activity.

* The ecosystem lacks a visual layer that shows token adoption and user behavior.

* Users can’t flex their onchain vibes socially in the same way they flex casts or followers.

________________


2. Solution Overview
Bluera introduces the idea of an onchain aura — a visual identity layer that maps your FID to your wallet activity on Base.
   * Ecosystem Heatmaps show token activity across Base.

   * User Auras show each FID’s trading footprint.

   * Leaderboards gamify activity (volume + tx count).

   * Shareable Cards turn all outputs into viral social objects.

👉 Your casts show what you say.
Your Bluera shows what you radiate onchain.
________________


3. Core Features (V1 Scope)
1. Token Heatmap (Ecosystem View)
      * Tracks whitelisted Base tokens (e.g. USDC, ETH, AERO, DEGEN, NOICE, WBTC).

      * Aggregates trading volume + tx count for September (and ongoing).

      * Displays heatmap grid → brighter glow = higher activity.

      * Output: “Monthly Token Aura” shareable card.

________________


2. User Heatmap (FID View)
         * Maps FIDs (starting db of ~6k top accounts) → wallets.

         * Aggregates each user’s trading activity:

            * Cumulative tx count per token.

            * Cumulative trading volume per token.

               * Generates personal aura card (heatmap + tagline).

________________


3. Leaderboard
                  * Ranks users by:

                     * Total transaction count.

                     * Total trading volume.

                        * Filters: “All time” and “This month.”

                        * Output: rank cards (e.g. “@bob.eth is #7 with 420 tx this month”).

________________


4. Wallet Connect (New Users)
                           * Any Farcaster user can connect wallets via Mini App SDK.

                           * Instant scan → generate their first Bluera.

                           * Frictionless onboarding: wallet → stats → aura card in <1 min.

________________


5. Shareable Aura Cards
                              * All outputs (ecosystem heatmaps, user auras, leaderboard ranks) export as Base-blue glowing cards.

                              * One-click share to Warpcast via Mini App SDK.

                              * Viral loop: cards in feeds drive FOMO → “Drop your FID to get your Bluera.”

________________


4. Stretch Features (Week 2 / Public Launch)
                                 * Badges → “Most traded token,” “Onchain OG,” “DEX maxxer.”

                                 * Similarity Index → find aura twins.

                                 * Streaks → daily activity tracker.

                                 * Social Mentions Overlay → outer glow based on token chatter in casts.

________________


5. User Journeys
Existing FID (in db)
                                    1. Open Bluera → see their mapped wallets.

                                    2. Personal aura heatmap auto-generated.

                                    3. Share their Bluera card to feed.

New User
                                       1. Connect wallet to FID.

                                       2. Wallet scanned → aura generated.

                                       3. Share Bluera → flex identity.

Ecosystem
                                          * Protocols see which tokens dominate activity.

                                          * Users see cultural + financial adoption patterns side by side.






🔵 Bluera — Token & User Classification Framework
________________


1. General Token-Level Metrics (Ecosystem View)
These metrics classify tokens in the Base ecosystem and can be used to build ecosystem-level heatmaps.
Core Metrics (V1 Candidates)
                                             * Trading Volume → total $ value traded (buy + sell).

                                             * Transaction Count → how many swaps/interactions happened.

Alternative / Extended Metrics
                                                1. Liquidity & Depth

                                                   * TVL in pools, active LP positions.

                                                   * Reveals tokens that anchor DeFi liquidity.

                                                      2.                                                       * How many distinct wallets traded/held the token.

                                                      * Captures adoption breadth vs. whale dominance.

                                                         3. Stickiness / Holding Duration

                                                            * Average time users hold before selling.

                                                               4. Distinguishes “hot potato memes” vs. “sticky stables/infra.”Unique Wallet Interactions


                                                               5. Protocol Distribution

                                                                  * Where the token is most used (DEX vs. lending vs. bridges).

                                                                  * Adds dimension of functional role in ecosystem.

                                                                     6. Social Momentum Overlay

                                                                        * Mentions in Farcaster casts.

                                                                        * Correlates onchain activity with cultural buzz.

                                                                           7. Net Flows

                                                                              * Inflow vs. outflow (are wallets accumulating or dumping).

                                                                                 8. Concentration

                                                                                    * % of supply/volume held by top 10 wallets.

                                                                                    * Exposes whale vs. grassroots tokens.

________________


2. User-Level Token Classifications (FID View)
These metrics classify users’ behavior across tokens and can be shown in personal heatmaps.
Core Metrics (V1 Candidates)
                                                                                       * Cumulative Volume per Token

                                                                                       * Transaction Count per Token

Alternative / Extended Metrics
Trading Style
                                                                                          * Activity Frequency → daily, weekly, monthly.

                                                                                          * Trade Size Distribution → whale vs. grinder.

                                                                                          * Holding vs. Flipping → % long-held vs. quick sells.

                                                                                          * Net Buyer vs. Seller → are they accumulating or dumping?

Token Engagement
                                                                                             * Diversity Score → number of unique tokens traded.

                                                                                             * Dominant Token → largest share of their activity.

                                                                                             * Breadth vs. Depth → maxi vs. explorer.

Liquidity Participation
                                                                                                * LP Positions → user acts as liquidity provider or not.

                                                                                                * % of LP vs. swaps → passive vs. active trader.

                                                                                                * Concentration → spread across one pool vs. many.

Ecosystem Participation
                                                                                                   * DEX Split → % activity on Uniswap vs Aerodrome vs BaseSwap.

                                                                                                   * Protocol Footprint → how much is swaps vs lending vs bridging.

                                                                                                   * Meme vs Infra Split → degen play vs infrastructure tokens.

Social + Onchain Hybrid
                                                                                                      * Talk vs Trade → do they cast about tokens they also trade?

                                                                                                      * Hype Trader Score → correlation between Farcaster chatter and trade timing.

                                                                                                      * Similarity Index → which other FIDs have a matching aura profile.

________________


3. Visualization Ideas
                                                                                                         * Tile Size = Wallet adoption / unique wallets

                                                                                                         * Glow Intensity = Trading volume

                                                                                                         * Hue = Net inflows vs outflows (red → selling, green → buying)

                                                                                                         * Outer Pulse = Social mentions / cultural buzz

On a user heatmap:
                                                                                                            * Tile glow = their volume share per token.

                                                                                                            * Tile size = how many transactions.

                                                                                                            * Hue shift = net buy vs net sell.

                                                                                                            * Outer aura = protocols or LP involvement.

________________


4. Potential User Personas (Badges/Flex Labels)
                                                                                                               * Whale Accumulator → few large trades, mostly buys.

                                                                                                               * Meme Sprinter → high tx count in degen tokens, short holding.

                                                                                                               * DEX Farmer → heavy LP, active on Aerodrome/Uniswap.

                                                                                                               * Maxi → 80%+ activity in one token.

                                                                                                               * Explorer → trades 10+ tokens per month.

                                                                                                               * OG → early wallet, still active.

________________


5. Suggested Approach for V1 vs Future
                                                                                                                  * V1 (Hackathon):

                                                                                                                     * Trading Volume + Tx Count (ecosystem & user heatmaps).

                                                                                                                     * Leaderboards (volume + tx).

                                                                                                                     * Shareable aura cards.

                                                                                                                        * V2+ (Post-hackathon):

                                                                                                                           * Add unique wallet counts, LP data, net flows.

                                                                                                                           * Add user classifications (breadth, streaks, hype trader).

                                                                                                                           * Social + onchain overlays for virality.

🔵 How Other Protocols Can Use Bluera Data
________________


1. Personalized Offers & Dynamic Pricing
                                                                                                                              * Lending Protocols → identify users with high LP volumes and offer boosted APRs or reduced fees to attract them.

                                                                                                                              * DEXs / Aggregators → reward frequent traders (or cross-DEX users) with reduced slippage or gas rebates.

                                                                                                                              * Yield Platforms → highlight curated vaults for users who consistently trade or LP a particular token.

                                                                                                                              * Insurance Protocols → tailor coverage offers to users with high exposure in specific pools.

👉 Differentiation: Instead of blind “airdrop farming,” they can target users with real onchain behavior.
________________


2. Segmentation for Campaigns, Airdrops & Giveaways
                                                                                                                                 * Token Projects → airdrop to wallets that have held longer (stickier community) rather than just anyone who traded.

                                                                                                                                 * Meme Coins → run campaigns targeting “high-frequency tx users” or “explorer wallets” who try many tokens.

                                                                                                                                 * NFT / Social Tokens → segment by meme vs infra trading preference → give perks to the most aligned community.

                                                                                                                                 * Cross-Chain Bridges → reward wallets that move stablecoins frequently.

👉 Position Bluera as a “segmentation oracle” → more educated targeting than generic snapshot tools.
________________


3. Partner Protocol Dashboards
                                                                                                                                    * Provide protocol-level Bluera dashboards showing:

                                                                                                                                       * Which FIDs are their top traders/LPs.

                                                                                                                                       * Overlap with other tokens/protocols.

                                                                                                                                       * “Who their users also are” in the ecosystem.

                                                                                                                                          * Example: Aerodrome can see if their LPs are also active in DEGEN or NOICE → informs co-marketing.

________________


4. Social Virality & Aura Cards as Campaign Assets
                                                                                                                                             * Protocols co-brand special edition aura cards:

                                                                                                                                                * “Uniswap Aura” → only for wallets that did >100 swaps on UNI pools.

                                                                                                                                                * “Aero OG Glow” → for top Aerodrome LPs.

                                                                                                                                                   * These become flex badges inside Farcaster → free distribution for the partner.

________________


5. Predictive & Risk Tools
                                                                                                                                                      * Risk Protocols (lending, insurance) → use trading/LP history to score wallets:

                                                                                                                                                         * High turnover = risky.

                                                                                                                                                         * Long-term LP = stable.

                                                                                                                                                            * Treasuries/DAOs → Bluera data shows which FIDs are whales vs broad community → informs governance outreach.

________________


6. Ecosystem-Wide Marketing Partnerships
                                                                                                                                                               * Base Ecosystem as a Whole

                                                                                                                                                                  * Monthly “Bluera Ecosystem Aura Report” → public heatmap showing adoption.

                                                                                                                                                                  * Protocols sponsor categories (“Presented by Aerodrome”).

                                                                                                                                                                     * Mini App Cross-Promotion

                                                                                                                                                                        * Other Mini Apps integrate Bluera to personalize onboarding flows:

                                                                                                                                                                           * A prediction market app can recommend markets if Bluera shows you’re a DEGEN-heavy trader.

                                                                                                                                                                           * A social token launchpad can target wallets with meme coin activity.

________________
